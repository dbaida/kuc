# AI Agents for Revenue Teams

Проект верстки секції з картками AI агентів для revenue teams.

## Структура

```
04-ai-agents/
├── index.html          # HTML розмітка
├── scss/
│   ├── main.scss       # Головний файл стилів
│   ├── main.css        # Скомпільований CSS
│   ├── utils/
│   │   ├── _variables.scss  # Змінні (кольори, шрифти, відступи)
│   │   └── _mixins.scss     # Mixins для перевикористання коду
│   ├── base/
│   │   └── _reset.scss      # CSS reset
│   └── components/
│       └── _card.scss       # Стилі карток
└── images/             # Зображення для карток
    ├── technical-questions.jpg
    ├── automate-rfps.jpg
    └── revenue-enablement.jpg
```

## Зображення

Для коректної роботи проекту потрібно додати три зображення в папку `images/`:

1. **technical-questions.jpg** - зображення для першої картки (велосипедист)
2. **automate-rfps.jpg** - зображення для другої картки (автомобіль)
3. **revenue-enablement.jpg** - зображення для третьої картки (офіс)

Зображення мають бути в форматі JPG або можна змінити формат в HTML.

## Компіляція SCSS

Для компіляції SCSS у CSS використовуйте:

```bash
sass scss/main.scss scss/main.css
```

Або для автоматичної компіляції під час змін:

```bash
sass --watch scss/main.scss scss/main.css
```

## Особливості реалізації

- ✅ Семантична HTML розмітка (section → h2 → article)
- ✅ Flexbox для розміщення 3 карток в ряд на десктопі
- ✅ Overlay з градієнтом для читабельності тексту
- ✅ Hover-ефект з плавною появою опису та кнопки
- ✅ Легке підняття картки та масштабування зображення на hover
- ✅ Адаптивний дизайн для мобільних пристроїв
- ✅ FAB (кругла іконка) у правому нижньому куті кожної картки
- ✅ Використання SCSS з модульною структурою

## Технічні деталі

- **Картки**: Висота 420px на десктопі, автоматична на мобільному
- **Overlay**: Градієнт від rgba(0,0,0,0.65) до прозорого
- **Hover**: Overlay посилюється до rgba(0,0,0,0.7), зображення масштабується на 1.03
- **Адаптивність**: На мобільних (< 768px) картки йдуть в один стовпець
- **Типографіка**: Використовується clamp() для адаптивних розмірів шрифтів
